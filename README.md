# Recomp & Golf Coach 🏋️⛳

**体脂肪25%→13% × 飛距離330yd / HS55m/s を同時に狙う、26歳・フルリモート向けのパーソナルコーチアプリ。**

3つの個人プラン(統合プラン / 理想の週間スケジュール / JOYFIT小台ジム動線ガイドv2)を、毎日iPhoneで使えるPWAに落とし込んだものです。完全無料・オフライン対応・iPhone 16 のホーム画面に追加してネイティブアプリのように使えます。

## 技術スタック

- **React + TypeScript + Vite**(PWA: `vite-plugin-pwa`)
- **ローカルファースト**: データは端末内(localStorage)に保存 → オフラインでも完全動作
- **Turso(libSQL)** : 任意でクラウド同期/複数端末バックアップ
- チャートは依存ゼロの自作SVG / アイコンは自作
- **完全無料**(GitHub Pages + GitHub Actions + Turso Hobbyプラン)

### データとプライバシー

GitHub Pages は静的配信で、配信されるJSは誰でも閲覧可能です。そのため **Tursoのトークンはビルドに埋め込みません**。設定画面で本人が入力したURL/トークンは**その端末のlocalStorageだけに保存**され、公開ファイルやリポジトリには一切含まれません。Tursoを設定しなくてもアプリは完全に動作します(その場合データは端末内のみ)。

## GitHub Pages へのデプロイ

`.github/workflows/deploy.yml` が用意済みです。`main` ブランチに push するだけで、ビルド → Pages へ自動デプロイされます。リポジトリ名から base パス(`/<repo>/`)も自動設定します。

### 手順

1. GitHub で新規リポジトリを作成(public でも private でも可)。
2. このフォルダを push:
   ```bash
   git remote add origin https://github.com/<あなた>/<repo>.git
   git branch -M main
   git push -u origin main
   ```
3. リポジトリの **Settings → Pages → Build and deployment → Source** を **「GitHub Actions」** に設定。
4. Actions タブでデプロイ完了を待つ → `https://<あなた>.github.io/<repo>/` で公開。
5. iPhone の Safari で開き、**共有 → ホーム画面に追加**。フルスクリーンのアプリとして使えます。

## Turso でクラウド同期(任意)

複数端末で同期したい・バックアップしたい場合のみ設定します。

1. [turso.tech](https://turso.tech) で無料アカウント作成(Hobbyプラン)。
2. CLI でDB作成:
   ```bash
   turso db create coach
   turso db show coach --url        # libsql://... のURLを取得
   turso db tokens create coach     # 認証トークンを発行
   ```
3. アプリの **設定 → クラウド同期** に URL とトークンを貼り付け → **接続テスト → 保存 → 今すぐ同期**。
4. テーブルは初回同期時に自動作成されます。以後は書き込みのたびに自動でバックグラウンド同期(last-write-wins)。

> 別端末でも同じURL/トークンを設定すれば、双方向に同期されます。

## このアプリが体現しているプランの要点

- **朝ジム型**(7時のほぼ貸切が最大の武器)・週5分割・睡眠7.5h死守
- **ボディリコンポジション**(週0.5kg減・タンパク質 体重×2g・クレアチン3-5g)
- **HS向上の3本柱**: バーベルコンパウンド / 回旋パワー+オーバースピード / 高タンパク軽赤字
- HS目標は **現実的射程51〜53m/s、55はストレッチ**(誇大広告に流されない設計)
- フェーズ分け(基礎→筋力→パワー→仕上げ)で2026年内に腹筋が見える状態へ
